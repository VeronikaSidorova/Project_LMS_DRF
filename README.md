# Проект LMS-системы

## Описание

Данный проект - это веб-приложение на Django с использованием DjangoRestFramework.\
Данное приложение - это LMS-система, в которой каждый желающий может размещать свои полезные материалы или курсы.

## Функции

Предусмотрена возможность регистрации и авторизации пользователя.\
Можно создать свой учебный курс и уроки к нему, оформить подписку на курс.\
Подключена возможность оплаты курсов через https://stripe.com/docs/api, с помощью сервисной функции.\
Для выполнения периодических задач приложение использует Celery.\
Реализована асинхронная рассылка писем: когда курс обновлен — тем, кто подписан на обновления именно этого курса, отправляется письмо на почту.\
С помощью celery-beat выполняется фоновая задача, которая проверяет пользователей по дате последнего входа и, если пользователь не заходил более месяца, он блокируется.

## Файл .env.sample

Файл `.env.sample` содержит шаблон переменных окружения, необходимых для настройки Вашего приложения. Он служит примером того, какие значения нужно установить в Вашем собственном `.env` файле.

### Запуск проекта

1. Установите Docker и Docker Compose, если они ещё не установлены.
2. В терминале, перейдите в директорию проекта.
3. Запустите команду: \
`docker-compose up`


### Проверка работоспособности

- **Бэкенд**: Откройте браузер и перейдите по адресу `http://localhost:8000`.
- **PostgreSQL**: Подключитесь к базе данных через pgAdmin или другой клиент.
- **Redis**: Используйте `redis-cli` для проверки подключения.
- **Celery** и **Celery Beat**: Проверьте логи в терминале, чтобы убедиться, что задачи выполняются без ошибок.

## Настройка удаленного сервера и деплоя

#### Требуемые пакеты и зависимости

1. Установите Python 3.13 и выше.
2. Установите Django версии 5.2 и выше. 
3. Установите Gunicorn и Nginx для обработки запросов.

#### Настройка сервера

1. Настройте SSH-доступ с использованием SSH-ключей для повышения безопасности. 
2. Закройте все ненужные порты, оставив открытыми только те, которые необходимы (например, 80 для HTTP и 443 для HTTPS). 
3. Установите и настройте Supervisor для автоматического перезапуска приложения при изменениях.


#### Деплой

1. Склонируйте репозиторий на сервер. 
2. Выполните миграции базы данных с помощью команды python manage.py migrate. 
3. Запустите сервер с помощью Gunicorn: gunicorn config.wsgi:application. 
4. Настройте Nginx для проксирования запросов к Gunicorn.
