# Проект LMS-системы

## Описание

Данный проект - это веб-приложение на Django с использованием DjangoRestFramework.\
Данное приложение - это LMS-система, в которой каждый желающий может размещать свои полезные материалы или курсы.

## Функции

Предусмотрена возможность регистрации и авторизации пользователя.\
Можно создать свой учебный курс и уроки к нему, оформить подписку на курс.\
Подключена возможность оплаты курсов через https://stripe.com/docs/api, с помощью сервисной функции.

## Файл .env.sample

Файл `.env.sample` содержит шаблон переменных окружения, необходимых для настройки Вашего приложения. Он служит примером того, какие значения нужно установить в Вашем собственном `.env` файле.

## Документация 

Для удобства работы с API Вашего приложения мы используем Redoc для генерации документации. Redoc предоставляет интуитивно понятный интерфейс для просмотра всех доступных эндпоинтов, их параметров и ответов.

### Доступ к документации

Документация API доступна по следующему URL:
```
http://127.0.0.1:8000/redoc/
```
